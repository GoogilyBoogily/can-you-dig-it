# Can dispenser configurator UX audit scope

Audit the current can-you-dig-it configurator in this working tree, including existing uncommitted features. The primary user is a person designing a printable can organizer who needs to choose cans, fit their shelf, inspect the result and download printable parts.

The audit follows the task sequence: understand the starting screen, configure one can size, configure different stacks, resolve fit problems, choose printing settings, inspect the preview, and export. Desktop and narrow layouts, keyboard operation, explanatory copy, progress and error states are included.

All existing capabilities must remain available. Recommendations may reorganize controls, disclose advanced settings progressively, clarify language, and improve feedback. This task produces an audit and implementation handoff; it does not change application behavior or dependencies. Existing user work is preserved.

Evidence combines running-browser inspection, source references and separate structural, visual, copy, accessibility and performance observations. Scores are heuristic expert assessments, not user-study results. No competitor comparison is assumed.
